# Imágenes de señales

Recursos raster generados una sola vez con la habilidad `imagegen` y la herramienta integrada, inspeccionados antes de incorporarlos. No se ejecuta generación de IA al emitir señales o reportes. Los PNG se guardan en el bucket privado de Telegram y después se reutiliza su `file_id`.

Prompts finales (herramienta integrada; fondo opaco):

- BUY: banner galáctico premium 1536×1024 para PROJECT GALAXY; astronauta con armadura metálica oscura, nebulosa violeta, vidrio holográfico morado, trayectoria ascendente verde esmeralda; tipografía metálica blanca “BUY”, “PROJECT GALAXY” y “BLACK GALAXY TRADE”; márgenes seguros; sin precios, resultados, porcentajes, promesas ni texto adicional.
- SELL: banner galáctico premium 1536×1024 para PROJECT GALAXY; astronauta con armadura metálica oscura a la izquierda, nebulosa violeta, paneles de vidrio morado, trayectoria descendente rojo rubí y arco planetario; tipografía metálica blanca “SELL”, “PROJECT GALAXY” y “BLACK GALAXY TRADE”; márgenes seguros; sin precios, resultados, porcentajes, promesas ni texto adicional.

La identidad de estrategia y los precios vigentes van en la explicación de cada mensaje. Los reportes estadísticos se renderizan como PNG a partir de sus datos, mediante código y WASM en el servidor.
